    article_summary: "Rust 1.96.0 正式发布，核心更新包括在 core::range 中引入了支持 Copy 语义的新 Range 类型，解决了旧版 Range 因实现 Iterator 而无法复制的问题。新版本还增加了 assert_matches! 宏，用于在断言模式匹配失败时提供更详尽的调试信息。WebAssembly 目标现在默认禁止未定义符号以减少构建错误，同时 Cargo 修复了两个影响第三方仓库的安全漏洞。此外，LazyCell 和 LazyLock 等多个 API 也在此版本中获得稳定。"
    discussion_summary: "社区对 Range 类型支持 Copy 反应积极，认为这解决了长期以来的易用性痛点，并肯定了 Rust 版本系统在处理此类破坏性变更时的优势。开发者们非常欢迎 assert_matches! 进入标准库，因为它能有效减少项目对小型第三方库的依赖。针对新旧 Range 类型并存可能导致的 IDE 自动导入歧义，讨论中也给出了相应的工具处理建议。"
