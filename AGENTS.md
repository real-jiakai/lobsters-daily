# AGENTS.md

Guidance for AI coding agents working in this repository.

## Project overview

Lobsters Daily publishes a daily snapshot of the top 10 stories on the
[Lobsters](https://lobste.rs) front page, captured at 23:00 UTC. Live at
https://lobsters.gujiakai.top. Two independent parts:

1. **Astro static site** (repo root) — renders the digest archive, deployed on
   Cloudflare Pages.
2. **Cloudflare Worker** (`worker/`) — daily cron that fetches
   `lobste.rs/hottest.json` and commits a new digest markdown file to this
   repo via the GitHub Contents API, which triggers a Pages rebuild.

The root and `worker/` are **separate pnpm packages** with separate lockfiles;
run `pnpm install` in each as needed. Node version is pinned in
`.node-version` (22.x).

## Commands

Site (repo root):

```bash
pnpm install
pnpm dev       # local dev server
pnpm build     # production build → dist/
pnpm check     # astro check (type-checks .astro/.ts)
```

Worker (`worker/`):

```bash
pnpm install
pnpm dev              # wrangler dev
pnpm run deploy       # wrangler deploy
npx tsx test-local.ts # run the digest pipeline locally; writes
                      # worker/test-output.md (gitignored), commits nothing
```

There is no test suite or linter beyond `astro check`; use
`worker/test-local.ts` to verify worker changes end to end.

## Architecture and data flow

1. Cron (`0 23 * * *`, configured in `worker/wrangler.toml`) fires the worker.
2. Worker fetches the top `DIGEST_TOP_N` (default 10, max 25) stories from
   `lobste.rs/hottest.json` and validates each item.
3. It renders a markdown file with YAML frontmatter and commits it to
   `src/content/digests/YYYY-MM-DD.md` on `GITHUB_BRANCH` with message
   `📝 Daily digest: YYYY-MM-DD`.
4. The commit triggers a Cloudflare Pages rebuild of the Astro site.

Failure handling: each step retries 3× with backoff (`withRetry` in
`worker/src/index.ts`); on final failure a plain-text alert is POSTed to
`ALERT_WEBHOOK` if set. `GET /trigger` with `Authorization: Bearer
<TRIGGER_TOKEN>` runs the digest manually; the endpoint is disabled while
`TRIGGER_TOKEN` is unset.

Worker configuration lives in `worker/wrangler.toml` (vars: `GITHUB_REPO`,
`GITHUB_BRANCH`, `DIGEST_TOP_N`). Secrets (`GITHUB_TOKEN`, `TRIGGER_TOKEN`,
`ALERT_WEBHOOK`) are set with `wrangler secret put`.

## Digest content format

Digests are an Astro content collection defined in `src/content.config.ts`:

```yaml
title: "Lobsters Daily — YYYY-MM-DD"
date: "YYYY-MM-DD"
items:
  - title: string
    url: string          # article URL (falls back to the Lobsters URL)
    lobsters_url: string # Lobsters discussion URL
```

**Keep the zod schema in `src/content.config.ts` and the markdown generation
in `worker/src/index.ts` in sync** — they are the two halves of one contract.

## Site structure

- `src/pages/index.astro` — latest digest / home page
- `src/pages/digest/[date].astro` — one page per digest (static paths from
  the collection)
- `src/pages/rss.xml.ts` — RSS feed
- `src/components/ArchiveNav.astro`, `MobileDrawer.astro` — archive navigation
- `src/layouts/Base.astro` — shared layout
- Styling is UnoCSS (Wind3 preset) with a custom `lobster` color palette in
  `uno.config.ts`; prefer utility classes and the existing palette.

## Conventions

- **All dates are UTC** — digest `X` is the front page as of 23:00 UTC on
  day `X`. Don't introduce local-time logic.
- **Never hand-edit or hand-create files in `src/content/digests/`** — they
  are generated by the worker. Fix generation bugs in `worker/src/index.ts`
  instead.
- The site renders only what the schema stores: a bulleted list of story
  links with a `(comments)` link each. No summaries or scores by design.
- Daily digest commits (`📝 Daily digest: ...`) land on `main` continuously;
  rebase or pull before pushing.
